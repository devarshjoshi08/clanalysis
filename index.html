    Process + Adobe Data Preparation

    One click: split your content-log emails, use them to mark each student's MAU / login in the reporting template, and generate the final Adobe summary — no manual Excel steps.

    • Select the same content-log files you use for the Email Extractor.
    • Created & "Created public link" emails → Completed MAU?; all other action emails → Logged In?.
    • First MAU Date (Raw_Data) = the date of each student's earliest Created / "Created public link" action in the selected logs, in India time (IST).
    • The template roster (Adobe_Reporting_Template.xlsm) is loaded automatically each run; your template file is never changed and nothing is left behind.

    Speed: the roster is cached in your browser after the first run, so most runs finish in ~1–2 s. Only the first run (or the first after you update the template) downloads & parses the ~24 MB file (~10–30 s). Use Chrome or Edge on a desktop, served over http/https (not a file:// double-click).
